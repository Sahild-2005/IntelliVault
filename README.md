# 🔐 IntelliVault

> AI-Powered Secure Document Management Platform

IntelliVault is a modern full-stack web application that enables users to securely upload, organize, analyze, and interact with documents using Artificial Intelligence.

It combines secure cloud storage, AI-powered document analysis, PDF chat, folder organization, and public sharing into one platform.

---

## 🌐 Live Demo

**Frontend:** https://intelli-vault.vercel.app

**Backend:** https://intellivault-api-518m.onrender.com

---

## ✨ Features

- 🔐 Secure JWT Authentication
- 📄 Upload PDF & Images
- ☁️ Cloudinary File Storage
- 🤖 AI Document Analysis
- 💬 Chat with PDF using Gemini AI
- 📁 Folder Management
- 🔗 Public Share Links
- 📊 Analytics Dashboard
- 🌙 Dark / Light Theme
- 📱 Responsive Design
